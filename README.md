# 💱 Live Currency Converter Website

A modern Currency Converter Website built using Flask, HTML, CSS, and JavaScript.

## Features

- 🌍 Live Exchange Rates
- 💱 20+ Currency Support
- 🔄 Swap Currency
- 📋 Copy Result
- 🗑 Clear Form
- 📱 Responsive Design
- ⚡ Fast & Lightweight

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Requests API

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
